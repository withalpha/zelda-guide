初始空岛——大天空岛上的祖纳依遗迹入口

📋 任务步骤
  1. 游戏开始，与泽尔达公主一同前往海拉鲁城堡地底调查红色淤泥异变。
  2. 在地底深处发现被封印千年的加侬多夫干尸，封印突然崩解，链克右臂被侵蚀。
  3. 大地震发生，链克与泽尔达被弹飞——链克单独落在大天空岛上醒来，右臂已被一只古代神手取代。
  4. 在岛上遇到拉乌鲁的残影，他说明神手的能力需要先激活三个神庙来恢复。
  5. 完成乌科乌神庙（究极手）→ 茵加尔神庙（余料建造）→ 格班神庙（通天术）。
  6. 途中顺路激活各处视野点，善用「余料建造」制作木筏或飞行器跨越大裂缝。
  7. 进入「时间庭园」，解开需要倒转乾坤的谜题，从拉乌鲁手中获得完整的神手能力。
  8. 学会倒转乾坤后，将庭园中央的巨石发射升空，链克踩上岩石飞出天空岛，向下跳落。
💡 实用技巧
  1. 大天空岛资源有限，不要浪费武器在弱小敌人身上，优先用棍棒和石块。
  2. 「余料建造」制作的「木板+木桩」可快速建造简易桥梁。
  3. 时间庭园谜题：先用余料建造把铁球固定到升降台，再用倒转乾坤反转轨道。

监视堡垒——海拉鲁中央平原的前线据点

📋 任务步骤
  1. 从大天空岛跳下，利用滑翔伞降落到海拉鲁中央平原（坐标约 0, 0, 100 附近）。
  2. 在平原上遇到士兵，跟随指引向北抵达监视堡垒（Lookout Landing）。
  3. 与军事顾问普尔鲁对话，她在瞭望塔顶层等待，爬上塔顶与她汇合。
  4. 使用塔顶的望远镜观察远方浮空的海拉鲁城堡，确认红色淤泥笼罩城堡。
  5. 普尔鲁说明利特村、卓拉领地、鼓隆城、格鲁德各地均有异变，委托链克调查。
  6. 激活监视堡垒视野塔，解锁中央平原地图区域，拍摄鸟瞰照片。
  7. 在堡垒内与队长霍兹对话，完成「海拉鲁城堡危机」支线，解锁城堡调查权限。
💡 提示：监视堡垒有盔甲商店、料理锅、床铺，建议在此补充道具和料理后再出发探索四大地区。

浮空的海拉鲁城堡——四大地区异变的源头

📋 四大地区概览与到达方式
  1. 🪶 利特村（西北·赫布拉山）：从监视堡垒向西北出发，经过里纳尔高原和赫布拉山脉。需耐寒装备（海拉鲁辣椒料理或防寒铠甲）。推荐首攻，难度最低。
  2. 💧 卓拉领地（东北·拉纳尤鱼湖）：从监视堡垒向东北方沿里纳尔山脉前进，途中会被淤泥雨攻击。准备泼水果或防淤泥盾牌。
  3. 🔥 鼓隆城（东北·艾勒纳塔克火山）：火山地区，需防火装备（防火铠甲或耐热料理），从里纳尔高原东侧绕行。
  4. ⚡ 格鲁德小镇（西南·格鲁德沙漠）：白天极热（耐热料理）、进镇需变装（格鲁德套装）。从南道进入沙漠难度最高，建议最后攻略。
⭐ 推荐顺序
  1. 利特村（最易上手，丘栗风力能力实用）→
  2. 卓拉领地（水系地区，希多水球盾牌很强）→
  3. 鼓隆城（阿沅翻滚技可破岩，探矿方便）→
  4. 格鲁德（露珠雷电箭矢，搭配弓箭强力）

拍下地底人

▼

约沙展示神秘石板上的地底构装体图像

📋 任务步骤
  1. 在监视堡垒二楼研究室找到女研究员约沙和男探险家多罗。
  2. 约沙展示一张从地底带回的神秘石板，上面刻有奇怪的构装体图像。
  3. 约沙委托链克下到地底，用相机拍摄更清晰的活动构装体照片。
  4. 找到监视堡垒附近的海拉鲁平原地底裂缝（坐标约 -0252, -0111），跳入进入地底世界。
  5. 在地底激活最近的破魔树根照明区域，眼睛适应黑暗后寻找发光的古代构装体。
  6. 靠近构装体，使用普鲁亚手机相机功能对准构装体拍摄（对准后按A确认）。
  7. 返回地面，将照片交给约沙，触发后续剧情「地底世界之谜」。
💡 提示：地底世界极度黑暗，建议携带多个「发光果」投掷照明，或先合成一盏「发光果+盾牌」当随身灯笼。

暴风圣舟——漂浮于赫布拉山暴风中心的风之神殿

📋 任务步骤
  1. 前往利特村：从监视堡垒向西北穿越里纳尔高原。准备耐寒料理（2颗辣椒+肉即可）。
  2. 到达利特村，与里冯（丘栗父亲、神殿贤者后裔）对话，了解暴风封锁情况。
  3. 在村外赫布拉山侧找到独自调查的丘栗，与他同行。丘栗具有「风之冲刺」能力，可推动风车。
  4. 格鲁登（巨型天空神鸟）被暴风困住无法飞行，需先找到散落在山中的4颗翅膀灵石解救格鲁登。
  5. 骑上格鲁登，借助气流高速突破暴风漩涡，登上空中的风之神殿（暴风圣舟）。
  6. 神殿内部：找到5个「解锁符文」风车机关，每个风车需先清除冰封障碍，再让丘栗吹动。
    · 1F：找齿轮拼合打开南侧门
    · 2F：用余料建造连接风力管道
    · 3F：在旋转平台上利用通天术穿越
    · 4F/5F：联动风车，依次开启
🔴 BOSS：寇加（Colgera）·深渊之甲
大型蜈蚣状飞行生物，身体分段穿越冰壁。攻略：用弓箭射击其三处冰晶核心（滑翔时瞄准最有效），击碎后趁机近战攻击金色弱点。共需击破3次。注意躲避从天而降的冰柱攻击。
🎁 通关奖励
  1. 召唤风之贤者丘栗，获得「疾风冲刺」贤者能力——可在空中追加一次冲刺。
  2. 利特村暴风解除，村民恢复正常生活，里冯处可购买利特族专属装备。

深藏于地底世界的灵殿遗迹

📋 任务步骤
  1. 完成四大地区任意一个神殿后，返回监视堡垒二楼研究室，触发约沙与多罗的新对话。
  2. 多罗坚持要亲自下到地底实地调查，约沙无法阻止，委托链克跟随多罗保护其安全。
  3. 在海拉鲁平原裂缝附近找到多罗，与他同行下到地底中央区域。
  4. 在地底中央找到一具巨型古代构装体残骸，外形与米涅露的构装体相似。
  5. 多罗记录下残骸上的古代佐纳依文字，这些文字将成为解开灵殿之谜的关键线索。
  6. 任务完成后触发「环卡遗迹的秘密」任务线，同时多罗开始在地底建立研究据点。
💡 地底探索建议：地底每个破魔树根激活后会回复生命，可作为补血点。中央地底地形相对平坦，是入门地底探索的好起点。

卓拉领地广场上被淤泥覆盖的「转潮石像」

📋 任务步骤
  1. 抵达卓拉领地（东北部），与外围卓拉族战士对话，了解领地内出现淤泥怪物。
  2. 进入领地广场，遇见尤娜（希多的未婚妻），她正在调查被淤泥覆盖的「转潮石像」。
  3. 采集泼水果（卓拉领地周边树丛、附近瀑布旁均有）至少 5~10 颗。
  4. 对准淤泥处投掷泼水果（按 R 键投掷）清除石像表面的淤泥。也可使用普通水箭或史莱姆果。
  5. 清理完成后石像现出全貌，触发尤娜的感谢对话，开启「修复卓拉铠甲」「碎裂的石碑」两条新主线。
💡 提示：淤泥被水冲洗后会消失。把泼水果融合到箭矢上射击远处淤泥效率最高，也可应对路上的淤泥怪物。

碎裂的石碑
在托托湖打捞古代石板碎片，由学者贾托翻译解读，揭示通往天空的关键线索。
剧情线 ▲ 卓拉领地
▼

学者贾托在托托湖检视打捞上来的卓拉石板

📋 任务步骤
  1. 清洗完转潮石像后，前往卓拉领地东北的托托湖。
  2. 在湖边找到贾托，他正烦恼一块沉入湖底的卓拉古代石板。
  3. 潜入湖中（卓拉铠甲修复后效率更高），将分散在湖底的3 块石板碎片用究极手粘合。
  4. 把拼合的完整石板搬上岸交给贾托，他翻译出古文：「朝雷之鳞鱼之地的水滴射出王之印」。
  5. 这段译文是「前往天空的线索」的关键，触发主线 10「前往天空的线索」。
💡 提示：湖底石板看起来散得很开，可以先用究极手抓起一块再吸附其他碎片，自动拼合成完整石板。

修复卓拉铠甲
为尤娜寻找古代亚罗瓦那鱼鳞，由铁匠丹托修复卓拉铠甲，恢复水中冲浪与攀瀑能力。
神殿前置 ▲ 卓拉领地
▼

尤娜在卓拉领地等待链克带回鱼鳞

📋 任务步骤
  1. 与尤娜对话后，找到铁匠丹托，他指出修复需要 1 片古代亚罗瓦那鳞。
  2. 古代亚罗瓦那只在普洛米斯山·米法雕像所在的「米法庭」附近水域出现。
  3. 从卓拉领地一路沿瀑布向上攀登（穿原版卓拉铠甲可攀瀑），抵达普洛米斯山顶。
  4. 在米法雕像附近的水池中找到一只巨大发光的鱼，潜水靠近抓住它，获得鱼鳞。
  5. 带回卓拉领地交给尤娜，她当场为链克修复并升级卓拉铠甲，从此水中游速提升、可顺瀑流而上。
💡 提示：米法庭周边有红色和银色波克布林。如不想战斗，可以骑上鱼快速冲到对岸再绕过去。卓拉铠甲修复后是攻略水之神殿的必需装备。

通向天空的水之神殿——浮在卓拉领地上空

📋 任务步骤
  1. 修复卓拉铠甲后，与卓拉国王多雷凡会面（在卓拉领地东方山中养伤的洞窟内）。
  2. 多雷凡告知传说：「朝雷鱼之地的水滴射王之印」对应普洛米斯山顶。
  3. 登上普洛米斯山顶（米法雕像处），在山顶环顾四周可看到天空中飘浮一个巨大水滴。
  4. 在山顶找到「王之印」标志（金色徽章），瞄准空中水滴的中心位置。
  5. 装备普通箭矢，射击水滴中心 → 触发天空裂缝降下，从中升起一座小岛。
  6. 站在升起的平台上一同被带到天空，触发剧情，希多王子从中飞出，邀请链克挑战水之神殿。

悬浮于卓拉上空的水之神殿（旧名：泉源岛）

📋 任务步骤
  1. 水滴升空后，与希多王子同行，希多自带「水球护盾」可格挡攻击。
  2. 抵达水之神殿，整座神殿是漂浮的圆盘形结构，中央有一个大水柱。
  3. 神殿目标：依次启动4 个水栓机关，让水流回到中央水柱。
  4. 1号水栓（西侧）：水管堵塞，用究极手把巨大齿轮装上轴心，转动激活。
  5. 2号水栓（东侧）：滚动巨石撞开闸门，沿水管逆流游上去。
  6. 3号水栓（北侧）：使用倒转乾坤把下落的水球反向送上高台。
  7. 4号水栓（南侧）：与希多合作，他喷射水球清除淤泥怪物，链克跳上水管。
  8. 4 栓全开后回到中央，巨型水柱激活，进入 BOSS 战。
🔴 BOSS：秽王水章鱼（Mucktorok）
第一阶段：章鱼骑在淤泥上滑行攻击，用泼水果箭矢清掉淤泥后用近战追击章鱼本体。
第二阶段：章鱼变成淤泥鲨鱼游动，瞄准它跃出淤泥的瞬间用泼水果命中，使其落地后近战。
· 推荐使用希多的水球箭矢（贤者能力）一键浇灭淤泥。
🎁 通关奖励
  1. 召唤水之贤者希多，获得「希多水箭/水盾」贤者能力，自动制造防护水罩。
  2. 卓拉领地恢复正常水流，多雷凡国王痊愈，希多正式继位。

深入岩浆地底搭乘矿车到达火之神殿，找到 8 名失踪鼓隆族，最终击败炎熔哥玛。

▼

火之神殿——艾勒纳塔克火山地底的螺旋熔岩遗迹

📋 任务步骤
  1. 抵达鼓隆城，发现整族都在沉迷食用「岩石蛋糕」（其实是邪恶物质）。
  2. 族长之子阿沅同样上瘾，用清醒蘑菇蛋糕（料理：清醒蘑菇 ×3 + 普通蛋）使其恢复神智。
  3. 阿沅说出岩石蛋糕来自地底深处的矿场，与他一起搭乘矿车下到艾勒纳塔克熔岩区。
  4. 沿矿车轨道一路追击 → 抵达地底深处的火之神殿入口。
  5. 神殿内部：找回 5 位被困鼓隆族的火之贤者祖先碑文（散落在 5 层楼）。
    · 利用阿沅的「滚石冲击」能力击碎挡路的岩柱。
    · 多用矿车 + 究极手 + 风扇组装动力车跨越熔岩。
