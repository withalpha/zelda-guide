紧闭的大门 / 初始空岛
与泽尔达公主调查城堡地底异变，被冲上大天空岛，习得四种新能力后降落海拉鲁。

初始空岛——大天空岛上的祖纳依遗迹入口

开场即是主线起点：与泽尔达一同调查城堡地底，封印崩解后你独自醒在初始空岛，右臂换成古代神手。这一段就是新手教学：拿齐四种能力才能离岛。

一、任务前置

  • 无，游戏开场自动开始。

二、任务步骤

  1. 与泽尔达下到城堡地底，见证加侬多夫封印崩解。
  2. 在初始空岛醒来，跟随拉乌鲁残影的指引行动。
  3. 完成乌可乌侯神庙拿究极手，伊恩伊萨神庙拿余料建造，古塔恩巴奇神庙拿通天术。
  4. 前往时间神殿，获得倒转乾坤。
  5. 从天空岛跃下，落入海拉鲁。

三、翻车点（防坑必看）

  • 别在空岛上跟强敌硬拼，初期武器很脆。
  • 余料建造多练，木板木桩搭桥、做筏是后面常态。
  • 时间神殿的谜题关键是倒转乾坤，别只用蛮力推。

四、奖励

四种神手能力齐全，主线正式展开。

02
监视堡垒
降落海拉鲁后前往监视堡垒与普尔鲁汇合，了解各地异变情报，触发四大地区调查任务。
序章 ▲ 海拉鲁中央
▼

监视堡垒——海拉鲁中央平原的前线据点

落地后的第一个据点，也是整个主线的情报中心。在这里和普尔鲁汇合，激活鸟望塔、拿到滑翔伞，四地区调查才正式开始。

一、任务前置

  • 完成初始空岛，落入海拉鲁。

二、任务步骤

  1. 从天空岛跃下，落到中央平原，向北走到监视堡垒，与普尔鲁汇合。
  2. 激活监视堡垒鸟望塔，取得滑翔伞。
  3. 接下利特村、卓拉领地、鼓隆城、格鲁德四地调查委托。
  4. 在堡垒里补给料理和道具，再出发。

三、翻车点（防坑必看）

  • 鸟望塔不是可选项，不开就拿不到滑翔伞、推不动主线，别跳过。
  • 望远镜看浮空城堡是四座神殿全通后回来汇报时的剧情，不是初到时的步骤。
  • 别一落地就直奔城堡，浮空城堡现在还上不去。

四、奖励

主线调查网铺开，四条地区线全部解锁。

03
四个地区的异变调查
分别前往利特村、卓拉领地、鼓隆城、格鲁德小镇调查各地异变，四条线可自由并行推进。
序章 多路并行
▼

主线任务「四个地区的异变调查」截图

这不是一条线性任务，而是四条地区线共用一个总标题：利特村、卓拉领地、鼓隆城、格鲁德小镇。顺序完全自由，任选一条先打都行。

一、任务前置

  • 在监视堡垒接下委托，拿到滑翔伞。

二、任务步骤

  1. 西北去利特村，备好耐寒。
  2. 东北去卓拉领地，备泼水果对付淤泥。
  3. 东北火山区去鼓隆城，备防火。
  4. 西南沙漠去格鲁德小镇，备耐热耐寒，沙漠昼夜温差大。
  5. 四座神殿全部通关后，回监视堡垒找普尔鲁，完成总任务。

三、翻车点（防坑必看）

  • 所谓推荐顺序只是上手难度参考，不是硬性条件，别被顺序绑住。
  • 单座神殿打完不用特意回来，四座全通后再回监视堡垒。
  • 格鲁德不需要像前作那样变装进镇，别白准备套装。

四、奖励

四位贤者陆续加入，通往终局的路一条条打开。

04
拍下地底人
协助研究员约舒娅拍摄地底指路雕像，解锁相机功能与地底探索任务线。
剧情线 ▼ 地底世界
▼

约沙展示神秘石板上的地底构装体图像

地底线的开端。约舒娅在监视堡垒研究地底资料，请你下地底拍一张指路雕像的照片，相机是在地底由研究员罗比解锁的。

一、任务前置

  • 到达监视堡垒；最好先带一点发光果。

二、任务步骤

  1. 在监视堡垒研究室找约舒娅接任务。
  2. 从监视堡垒南边到海拉鲁平原裂缝，跳入地底。
  3. 在地底见到研究员罗比，由他解锁相机功能。
  4. 激活最近的破魔树根照明，找到指路雕像并拍下。
  5. 回地面把照片交给约舒娅。

三、翻车点（防坑必看）

  • 地底一片漆黑，没光寸步难行，发光果和破魔树根是命。
  • 破魔树根只恢复被瘴气侵蚀的心心上限，不回血，别把它当补血点。
  • 要拍的是指路雕像，不是泛指的构装体，拍错了不算完成。

四、奖励

相机功能解锁，另获海拉鲁图鉴与佐纳乌矿石；地底探索线由此展开。

05
利特村的丘栗 → 风之神殿
调查被暴风雪封锁的利特村，与小鸟丘栗并肩作战，登上风之神殿，击败急冻盖拉。
神殿攻略 ▲ 利特村 推荐首攻
▼

主线任务「利特村的丘栗」截图

利特村被暴风雪封锁，村里的小鸟丘栗成了你的搭档。两人登上空中的风之神殿，首领是急冻盖拉。

一、任务前置

  • 耐寒料理或防寒装备；已接下监视堡垒委托。

二、任务步骤

  1. 向西北到利特村，见村长特巴了解暴风情况。
  2. 按指引找哈茨，再到海布拉山南岳洞窟一带。
  3. 在塔隆托峰雪松树下找到丘栗，帮他取回弓，他才与你同行。
  4. 借助丘栗的风力登上风之神殿。
  5. 神殿内启动五座风车终端。
  6. 击败首领急冻盖拉。

三、翻车点（防坑必看）

  • 丘栗的父亲是村长特巴，不是其他名字，别按旧攻略找人。
  • 首领战多在滑翔中进行，瞄准它身上的冰晶弱点。
  • 丘栗的风力不仅能推风车，赶路和滑翔时也很好用。

四、奖励

风之贤者丘栗加入，获得疾风冲刺；利特村暴风解除。

06
沉睡于地底神殿之谜
完成一座神殿后，协助约舒娅调查地底中央大废矿，获得自动建造能力。
剧情线 ▼ 地底世界
▼

主线任务「沉睡于地底神殿之谜」截图

完成一座神殿后回监视堡垒，约舒娅请你去地底中央大废矿调查。在矿场，管家构装体会授予你自动建造能力。

一、任务前置

  • 完成任意一座神殿；已下过地底。

二、任务步骤

  1. 回监视堡垒研究室找约舒娅接任务。
  2. 前往地底中央大废矿。
  3. 在矿场见管家构装体，获得自动建造能力，并收集蓝图石。
  4. 回去向约舒娅交差。

三、翻车点（防坑必看）

  • 矿场里没有巨型构装体残骸可调查，别按旧说法找。
  • 本任务不开启灵殿与第五贤者线，那条线是城堡异变之后的另一条链。
  • 自动建造拿到后多用蓝图存常用载具，后面省很多事。

四、奖励

自动建造解锁。

07
被淤泥埋没的石像
卓拉领地中央被红色淤泥侵蚀的转潮石像需要清洗，开启卓拉领地剧情线。
剧情线 ▲ 卓拉领地
▼

卓拉领地广场上被淤泥覆盖的「转潮石像」

卓拉领地线的开场。领地广场中央的转潮石像被红色淤泥糊住，尤娜正在调查，帮她清淤就打开了卓拉领地整条剧情。

一、任务前置

  • 到达卓拉领地。

二、任务步骤

  1. 到卓拉领地广场，见到正在调查石像的尤娜。
  2. 在领地周边采集泼水果。
  3. 对淤泥投掷泼水果或用水系攻击清洗石像。
  4. 清完后与尤娜对话，推进后续剧情。

三、翻车点（防坑必看）

  • 石像就叫转潮石像，清淤后现出的是它本来的样子。
  • 把泼水果融合到箭上射远处淤泥，效率最高。

四、奖励

卓拉领地剧情线开启，尤娜成为后续任务的关键人物。

08
碎裂的石碑
在托托湖清理并拼合古代石板，由学者翻译解读，揭示通往天空的关键线索。
剧情线 ▲ 卓拉领地
▼

学者贾托在托托湖检视打捞上来的卓拉石板

清完石像后，托托湖边有一块卓拉石板缺了一块。清淤、把缺块嵌回原位，学者当场就能读出译文，里面藏着上天空的关键一句。

一、任务前置

  • 完成石像清淤。

二、任务步骤

  1. 前往卓拉领地正北、米法庭西北的托托湖找学者。
  2. 清掉石板上的淤泥。
  3. 用究极手把缺失的中央一块嵌回墙上原位。
  4. 学者当场读出译文：立于天空鱼之地，仰望高处；浮石之间有一滴水珠，穿过水滴射出带王之印的箭。
  5. 接下来去找多雷凡国王。

三、翻车点（防坑必看）

  • 没有湖底三块碎片和潜水打捞这一说，别下湖捞。
  • 石板不是交给学者带走翻译，是嵌回原位后当场读出来的。
  • 这一步做完是去找多雷凡国王，不是直接去普洛米斯山，普洛米斯山是修铠甲找鱼的地方。

四、奖励

获得前往天空的线索，卓拉线继续推进。

09
修复卓拉铠甲
把古代亚罗瓦那交给尤娜，由她修复卓拉铠甲，恢复水中冲浪与攀瀑能力。
神殿前置 ▲ 卓拉领地
▼

主线任务「修复卓拉铠甲」截图

尤娜手里有你以前留下的卓拉铠甲，只差最后一样东西就能修好：古代亚罗瓦那的鳞片。拿到它，攀瀑能力就回来了。

一、任务前置

  • 完成石像清淤，与尤娜对话；问铁匠丹托打听鱼的下落。

二、任务步骤

  1. 在卓拉领地找尤娜接任务。
  2. 找铁匠丹托，他说古代亚罗瓦那在普洛米斯山米法雕像附近的水域。
  3. 到米法庭的水池里捉到古代亚罗瓦那，天空岛水域也有。
  4. 把鱼交给尤娜，取回修好的卓拉铠甲。

三、翻车点（防坑必看）

  • 修铠甲的是尤娜，丹托只提供鱼的下落线索，别弄反。
  • 不需要先穿一件原版铠甲才能上山，步行就能到米法庭。
  • 拿到铠甲后才能攀瀑，水之神殿前务必先做完这一步。

四、奖励

卓拉铠甲入手，可以逆瀑而上；水之神殿前置完成。

10
前往天空的线索
取得王的鳞片后，在浮空鳞岛向天空鱼群的水滴空隙射出附鳞片之箭。
剧情线 ▲ 天空群岛
▼

主线任务「前往天空的线索」截图

石板译文的谜底揭晓：多雷凡国王给你五片王的鳞片，把其中一片附在箭上，在浮空鳞岛射穿天空鱼群的水滴空隙，天空之路就打开了。

一、任务前置

  • 修好卓拉铠甲；先与米法庭的希多对话，再到瀑布后的清流王居见多雷凡国王。

二、任务步骤

  1. 与多雷凡国王会面，取得五片王的鳞片。
  2. 前往浮空鳞岛。
  3. 站在岛上向西南看，漂浮岩石构成水滴形状。
  4. 把王的鳞片附在箭上，射穿水滴。
  5. 东储水湖升起绿色光柱，揭示古代卓拉祭殿入口。
  6. 回东储水湖见希多，经祭殿水路攀瀑而上，前往水之神殿。

三、翻车点（防坑必看）

  • 普通箭射不穿，关键是箭上附了王的鳞片。
  • 射箭点不是普洛米斯山顶，而是浮空鳞岛。
  • 射中后不是天空降下通路，别在岛上空等，先回东储水湖。

四、奖励

天空之路开启，水之神殿线正式开始。

11
卓拉领地的希多 → 水之神殿
与希多同行登上天空的水之神殿，启动四个水栓，击败淤泥莱克。
神殿攻略 ▲ 卓拉领地
▼

主线任务「卓拉领地的希多」截图

天空中的水之神殿，核心是让水流回到中央水柱：启动四个水栓。首领是淤泥莱克，希多的水球是你最好的帮手。

一、任务前置

  • 修好卓拉铠甲；完成前往天空的线索。

二、任务步骤

  1. 与希多同行进入水之神殿。
  2. 依次启动四个水栓，让水流回到中央。
  3. 回到中央水柱处。
  4. 与淤泥莱克决战。
  5. 打完回卓拉领地，多雷凡将王位交予希多。

三、翻车点（防坑必看）

  • 别按旧攻略记水栓方位，跟着神殿内的水管走向找。
  • 淤泥莱克本体藏在淤泥里，先用泼水果或希多的水球清掉淤泥再近战。

四、奖励

水之贤者希多加入，获得水球护盾能力；卓拉领地水流恢复，希多正式继位。

12
鼓隆城的阿沅 → 火之神殿
与阿沅同行深入地底火之神殿，敲响五口锣，击败熔岩巨人。
神殿攻略 ▲ 鼓隆城
▼

主线任务「鼓隆城的阿沅」截图

鼓隆城全族沉迷岩石烤肉，阿沅戴着面具神智不清。让他清醒过来，两人一起下到地底火之神殿，敲响五口锣，首领是熔岩巨人。

一、任务前置

  • 防火装备或耐热料理；已接下监视堡垒委托。

二、任务步骤

  1. 到鼓隆城了解岩石烤肉事件。
  2. 追上戴面具的阿沅，打碎面具让他恢复神智，与他同行。
  3. 上死亡火山途中备好防火，击败莫拉吉亚后从火山口跳入深渊，向西走到火之神殿。
  4. 用阿沅的滚石冲击敲响五口锣。
  5. 击败首领熔岩巨人（Marbled Gohma）。

三、翻车点（防坑必看）

  • 五口锣不是泛指的终端，分布在不同楼层，跟着锣声找。
  • 矿车只是上死亡火山途中的工具，进地底是跳火山口，不是坐矿车直达。
  • 防火是上死亡火山途中需要的，不是神殿里地面持续掉血。

四、奖励

火之贤者阿沅加入，获得滚石冲击；鼓隆城恢复正常。

13
格鲁德小镇的露珠 → 雷之神殿
协助露珠守护格鲁德小镇与沙漠避难所，破除沙暴，登上雷之神殿，击败女王基布德。
神殿攻略 ▲ 格鲁德
▼

主线任务「格鲁德小镇的露珠」截图

浮空的海拉鲁城堡——加侬多夫的瘴气源头

四座神殿全通、回监视堡垒向普尔鲁汇报后，普尔鲁指派你潜入浮空的海拉鲁城堡。城堡里那个泽尔达是假的，追踪她的幻影穿行各层，最终在圣所与幻影加侬决战。

一、任务前置

  • 四座神殿全部通关，并回监视堡垒向普尔鲁汇报。

二、任务步骤

  1. 回监视堡垒，接受普尔鲁的城堡潜入指派。
  2. 潜入浮空城堡，追踪泽尔达幻影穿行城堡各层。
  3. 到达圣所（王座大厅）与幻影加侬决战。
  4. 战后第五位贤者线索开启。

三、翻车点（防坑必看）

  • 前置不是一座神殿，而是四座全通，之前本任务一直处于暂停状态。
  • 霍兹搜索队是四神殿之前在第一门楼一带的内容，别和城堡潜入拼成一步。
  • 幻影加侬的攻击会削减心心上限，备好太阳花料理。
  • 第二波是五具幻影加侬齐出，没有单一本体可集中，先用弓箭爆头打断那具正在铺瘴气的，再逐个击破。

第五位贤者线索开启；城堡异变线告一段落。

主线任务「寻找第五位贤者」截图

第五位贤者是灵之贤者米涅露。本任务由普尔鲁交予，实际推进靠两条线：环卡遗迹的秘密和来自太古的指引，走完这两条线，米涅露加入，本任务完成。

一、任务前置

  • 四座神殿全通，海拉鲁城堡幻影加侬战后。

二、任务步骤

  1. 在监视堡垒从普尔鲁处接下寻找第五位贤者的任务。
  2. 前往卡卡利科村，调查上空的环卡遗迹。
  3. 登上龙首岛取得佐纳依遗物。
  4. 跟随遗物光束到法罗尼地底的构装体工厂。
  5. 在工厂周围四座仓库取回构装体零件，在工厂模具上组装。
  6. 乘组装好的构装体前往灵殿，击败被夺构装体，取回灵之秘石。
  7. 获得米涅露的誓约与心之容器，第五位贤者加入。

三、翻车点（防坑必看）

  • 环卡遗迹与太古指引不是本任务的前置，它们就是本任务的推进路径。
  • 零件不在鼓隆、利特、格鲁德地底，四座仓库都在法罗尼地底构装体工厂周围。
  • 组装在工厂模具上完成，灵殿是组装好之后乘构装体去的目的地，不是组装地点。

林克乘米涅露构装体

佐纳依遗物会发光指路，跟着光束走，你会来到法罗尼地底的构装体工厂。米涅露在这里正式现身，委托你收集零件、组装构装体、前往灵殿。

一、任务前置

  • 完成环卡遗迹的秘密，持有佐纳依遗物。

二、任务步骤

  1. 跟随遗物光束向法罗尼地底前进。
  2. 从地底裂缝进入构装体工厂。
  3. 把遗物放进工厂入口模具的头部槽位，米涅露正式现身。
  4. 接下收集构装体零件的委托。
  5. 在工厂周围四座仓库取回零件，在工厂模具上组装构装体。
  6. 乘组装好的构装体前往灵殿，击败被夺构装体，取回灵之秘石。
  7. 获得米涅露的誓约与心之容器。

三、翻车点（防坑必看）

  • 光束指向法罗尼地底，不是西南。
  • 米涅露正式现身在构装体工厂，不是灵殿前厅，灵殿是之后才去的地方。
  • 本任务不是纯剧情散步，含四座仓库解谜与被夺构装体首领战。

林克在光之龙头上拔取大师之剑

大师之剑插在光之龙头顶。拔剑的硬门槛是两轮满耐力：初始一轮加 5 个耐力容器，共 20 个祝福之光换来，临时黄色耐力不算。

一、任务前置

  • 两轮满耐力（初始一轮加 5 个耐力容器）；已获得大师之剑的位置标记。

二、任务步骤

  1. 按地图标记追上光之龙，登上龙头。
  2. 走到额头闪耀圣光的剑身前，按下交互。
  3. 按住拔剑，耐力持续消耗，直到拔出。
  4. 耐力不够会被弹开，追上光之龙再试一次。

三、翻车点（防坑必看）

  • 黄色临时耐力连救急都做不到，必须是绿色耐力凑满两轮。
  • 拔剑时光之龙会剧烈挣扎，别在半途松手。
  • 拔剑后别急着走，白龙身上的素材很值钱。

链克与魔王加侬多夫的最终对决

终局战分三个阶段：人形加侬多夫、觉醒态、魔王龙。贤者们全程随行助战，没有打五个魔影贤者这个固定流程。

一、任务前置

  • 四位贤者加入；灵之贤者米涅露加入；备好太阳花料理。

二、任务步骤

  1. 从海拉鲁城堡正下方裂缝跳入地底。
  2. 沿地底通道向南，穿过瘴气军团营地，到达瘴气巢穴。
  3. 与加侬多夫决战：人形态、觉醒态依次击败。
  4. 乘光之龙迎战魔王龙，击破背上四处眼睛脓包。
  5. 最后刺向额头上的秘石。

三、翻车点（防坑必看）

  • 瘴气攻击会锁心心上限，太阳花料理是标配。
  • 魔王龙的最后一击在额头秘石，不是胸前核心。
  • 贤者们是随行助战，不是固定流程里要打的敌人。
