📌 第一步：连接到你的路由器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法 1：使用 SSH 工具（推荐）
  • 下载 PuTTY 或使用 Windows Terminal
  • 输入路由器 IP（通常是 192.168.1.1）
  • 端口：22
  • 输入用户名：root
  • 输入密码

方法 2：使用路由器网页终端
  • 浏览器访问路由器管理页面
  • 找到 系统 → TTYD 终端 或 系统 → Terminal


📌 第二步：复制粘贴命令
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

选择一个文件：
  
  ✅ 正常情况：打开「一键安装命令.txt」
     • 全选复制里面的所有内容
     • 粘贴到 SSH 终端
     • 按回车执行
     
  ⚠️ 如果网络不好：打开「如果网络不通用这个.txt」
     • 使用国内镜像加速
     • 全选复制所有内容
     • 粘贴到 SSH 终端
     • 按回车执行


📌 第三步：等待完成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • 命令会自动执行所有操作
  • 大约需要 2-5 分钟
  • 看到 "✅ 安装完成！" 就成功了
  • 刷新路由器管理页面
  • 在 服务 → PassWall2 开始配置


🆘 如果遇到问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题 1：提示 "wget: command not found"
解决：先执行：opkg update && opkg install wget

问题 2：提示 "Network is unreachable"  
解决：使用「如果网络不通用这个.txt」的镜像版本

问题 3：依赖包安装失败
解决：执行以下命令查看详细信息并发给我
  opkg print-architecture
  cat /etc/openwrt_release
  opkg list | grep passwall

问题 4：主程序安装失败，提示架构不兼容
解决：可能需要强制安装依赖，执行：
  opkg install --force-depends luci-app-passwall2_26.6.3-r1_all.ipk


💡 提示
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• 整个过程中不要关闭 SSH 连接
• 如果卡住超过 5 分钟，按 Ctrl+C 取消，重新执行
• 安装完成后记得配置节点信息
• 第一次使用建议看官方文档配置教程
